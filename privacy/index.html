1. 개인정보의 처리 목적

깜빡(이하 "앱")은 다음 목적을 위해 최소한의 정보를 처리합니다.

  • 사람과 기념일(생일·결혼기념일·기일 등) 등록, 음력/양력 자동 변환
  • 기념일 알림, 홈 화면·잠금 화면 위젯, 잠금 화면 카운트다운 표시
  • 문장으로 등록하는 "깜빡 AI" 해석 및 기념일 요약(브리핑)
  • 말로 등록하는 음성 입력 (마이크 버튼을 눌렀을 때만)
  • 관계·나이대에 맞춘 선물 추천
  • 앱 개선을 위한 익명 사용 통계 (설정에서 끌 수 있음)

2. 기기에만 저장되는 정보

아래 정보는 사용자의 iPhone에만 저장되며, 깜빡 운영자나 외부 서버로 전송되지 않습니다.

항목내용처리 방식
사람 정보이름, 관계, 사진(선택), 전화번호(선택), 메모(선택)기기 내 저장
기념일 정보제목, 종류, 음력/양력 날짜, 연도(선택), 알림 설정기기 내 저장
깜빡 AI 입력 문장"엄마 생신 음력 3월 15일" 같은 입력 문장기기 안의 Apple Intelligence 또는 앱 내부 규칙으로만 해석, 저장·전송하지 않음
핵심 원칙: 이름·날짜·전화번호·메모·사진 같은 개인정보는 기기에만 있습니다. 로그인이 없고, 깜빡 운영자는 이 정보를 볼 수 없습니다.

3. 기기 밖으로 보내는 정보

대상보내는 내용목적
Google (Firebase Analytics)기능 사용 기록(예: 기념일 등록 횟수, AI 등록 성공 여부), 앱 설치 식별자, 기기 종류·OS 버전, IP 기반 대략적 지역앱 개선 통계. 이름·날짜 등 개인정보는 포함하지 않으며, 광고 추적에 쓰지 않습니다.
쿠팡 (쿠팡파트너스)선물 추천에서 "상품 보기"를 누를 때 해당 상품 검색어제휴 링크 생성. 사용자 개인정보는 보내지 않습니다.

사용 통계 끄기: 앱 > 설정 > 개인정보 > "사용 통계 보내기"를 끄면 Firebase로 아무것도 보내지 않습니다.

선물 추천 링크를 통해 쿠팡에서 구매하면 깜빡은 쿠팡파트너스 활동의 일환으로 일정 수수료를 받을 수 있습니다.

4. 보유 및 이용 기간

기기에 저장된 정보는 사용자가 삭제하거나 앱을 삭제할 때까지 보관됩니다. Firebase 사용 통계는 Google Analytics 데이터 보관 설정(2개월)에 따라 보관 후 자동 삭제됩니다.

5. 개인정보의 제3자 제공

깜빡은 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 3항의 사용 통계와 선물 검색어 전송은 서비스 제공을 위한 처리 위탁에 해당합니다.

6. 개인정보의 파기

  • 개별 삭제: 앱에서 사람이나 기념일을 삭제하면 즉시 파기됩니다. 사람을 삭제하면 연결된 기념일도 함께 삭제됩니다.
  • 전체 삭제: 앱을 삭제하면 기기 내 모든 데이터가 파기됩니다.
  • 백업 파일: 설정에서 만든 백업 파일은 사용자가 저장한 위치(파일 앱 등)에 있으며, 사용자가 직접 관리·삭제합니다.

7. 이용자의 권리

  • 등록한 정보의 열람·수정·삭제 (앱 안에서 언제든지)
  • 사용 통계 수집 거부 (앱 > 설정 > 개인정보)
  • 알림 수신 거부 (iOS 설정 > 깜빡 > 알림)
  • 마이크 권한 거부·철회 (iOS 설정 > 깜빡 > 마이크)

8. 개인정보 보호를 위한 기술적 조치

  • 데이터는 기기의 앱 전용 저장 공간에 저장되며, 기기 잠금이 처음 풀린 뒤에만 접근할 수 있도록 보호됩니다.
  • 외부 통신은 모두 HTTPS(TLS)로 암호화됩니다.
  • 깜빡 AI는 기기 안에서만 동작합니다.
  • 음성 입력은 마이크 버튼을 누른 동안만 듣고, 음성은 기기 안에서 글자로만 바뀝니다. 음성 자체는 저장하거나 기기 밖으로 보내지 않습니다. 사용 통계에는 음성 입력을 썼는지와 성공 여부만 보내며, 말한 내용은 보내지 않습니다.

9. 아동의 개인정보
